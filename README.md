## Selected work

### Adaptive-Precision Face Verification
A leakage-free two-tier face-verification pipeline that uses INT8 inference for most pairs and selectively rechecks borderline cases with FP32. The project evaluates accuracy, AUC, agreement, escalation rate, and confidence intervals on LFW.

[View the project](https://github.com/martian1998/Adaptive-Precision-Face-Verification)
